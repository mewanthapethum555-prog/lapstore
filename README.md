LapStore - Management System

LapStore is a modern desktop-based management application designed for laptop retail shops. Built with Java Swing, it provides a secure and aesthetically pleasing interface for employees to manage store operations. The application features a macOS-style premium UI and integrates seamlessly with a MySQL database for robust data management.

🚀 Key Features

•	Secure Authentication: Robust login system for employees with real-time MySQL database validation.

•	Modern UI/UX: Utilizes the FlatLaf Look and Feel (Laf) library to provide a sleek, "Flat Mac" dark and light theme experience.

•	User Dashboard: A personalized home screen displaying logged-in employee details.

•	Database Integration: Scalable architecture using JDBC for CRUD operations and data persistence.

•	Responsive Design: GUI built with NetBeans Form Editor for consistent layout performance.

🛠️ Technology Stack

•	Language: Java (JDK 17+)

•	GUI Framework: Java Swing

•	UI Library: FlatLaf (FlatMacDarkLaf & FlatMacLightLaf)

•	Database: MySQL

•	Driver: MySQL Connector/J

•	IDE: NetBeans

📋 Prerequisites

Before running the project, ensure you have the following installed:

•	Java Development Kit (JDK) (Version 17 or higher recommended)

•	MySQL Server
•	NetBeans IDE (Optional, but recommended for GUI editing)
